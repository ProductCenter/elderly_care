1. 产品概述与页面清单

康养行业生态服务商城，支持三类商品属性驱动的差异化履约：到店服务、到家服务、实物商品。

页面 文件 说明
商城首页index.html分类、主推卡、瀑布流商品列表
商品详情detail.html主图、价格、属性标签、门店/发货信息、购买
填写订单order.html按商品属性展示地址/门店/预约/运费
订单详情order-detail.html核销码（到店）/ 时间轴（到家·实物）
我的订单orders.html全部 / 待核销 / 已完成
个人中心mine.html订单入口、商家核销入口
商家核销merchant-verify.html扫码/手输核销演示

2. 商品属性与订单逻辑

属性字段：productAttr（兼容旧字段 serviceType）

属性 标签 下单页 履约
到店服务 短标签「到店」 门店信息 + 预约时间；无收货地址；无运费 支付后生成核销二维码，到店核销
到家服务 短标签「到家」 收货地址 + 预约上门时间 工单时间轴：下单→派工→确认→成功
实物商品 短标签「实物」 收货地址 + 运费；无预约 物流时间轴：下单→发货→运输→收货

3. 核心用户流程

到店服务

首页→详情→下单（门店+预约）→支付→订单详情（核销码）→商家核销

到家服务

首页→详情→下单（地址+预约）→支付→订单详情（服务进度）

实物商品

首页→详情→下单（地址+运费）→支付→订单详情（物流）

4. 设计规范

画板

移动端宽度 390px；状态栏 44px；导航栏 44px；微信胶囊约 87×32；底部安全区 safe-area-inset-bottom。

色板

#191919 主文字 #888 次要文字 #F7F7F7 页面底 #FF6146 价格 #FA5151 强调红 #3B82F6 主按钮/到店 #07C160 微信绿 #16A34A 到家标签 #0F766E 实物标签

字体

系统字体栈：PingFang SC / Helvetica Neue / Microsoft YaHei。标题约 17px 半粗；正文 14–15px；辅助 12–13px。

圆角与间距

卡片圆角 10–12px；页面水平边距 12px；卡片间距 10px；主按钮高度约 40px、圆角胶囊形。

6. 关键页面标注要点

商城首页

  • 顶部定位 + 搜索 + 横向分类
  • 左侧主推大卡 + 右侧优惠券/活动栈
  • 商品卡统一展示属性短标签（到店/到家/实物）+ 价格 + 月售
  • 底部 Tab：首页 / 健康 / 商城 / 我的

填写订单

  • 顶部只读属性徽章条（不可切换）
  • 到店：门店卡（地址/电话/营业）对齐网格
  • 到家/实物：收货地址行
  • 实物隐藏预约；到店/到家显示预约
  • 底部固定栏：合计 + 微信支付

订单详情（到店）

  • 待核销：状态文案仅「待核销」，不展示「已完成」
  • 核销区仅二维码（无条形码切换）
  • 多份核销码支持左右切换；已使用遮罩「已使用」
  • 门店地图预览 + 多地图导航
