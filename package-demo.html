套餐权益 HTML 用例

走通「后台上架 → 商城展示 → C 端下单支付 → 订单权益码 → 商家勾选核销」。 数据落在本机 localStorage，刷新不丢。

当前状态

按序点击走通

  1. 1
    后台上架套餐权益 商品类型=服务商品 · 形态=套餐权益 · 保存后写入草稿
    去上架
  2. 2
    商城查看已上架商品 首页精选 / 详情页会读取上架草稿覆盖名称与价格
    去详情
  3. 3
    C 端下单并支付 支付成功后生成权益配额（次数×天数）与动态权益码
    去下单
  4. 4
    用户订单 · 出示权益码 支付后自动跳转；也可从最近套餐订单进入
    订单列表
  5. 5
    商家核销 · 勾选扣次 切到「套餐权益」页签，解析 PK1 码后勾选今日项目
    去核销

验收要点

· 上架后详情页名称/售价应与后台一致
· 支付后订单详情出现「套餐权益码」二维码与剩余次数
· 商家勾选核销后，剩余次数减少；当日达上限的项目不可再勾
· 默认可服务日为周一至周六；周日核销会按规则拒绝
· 权益码约 3 分钟有效，可在订单详情点「刷新权益码」
